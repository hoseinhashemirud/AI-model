# Quarto Website Deployment

## Project

This repository contains the Artificial Intelligence course website built with Quarto.

## Workflow

The website development process included:

1. Resolving the existing Pull Request issues and merge conflicts.
2. Updating the `main` branch with the finalized Quarto website.
3. Configuring GitHub Actions for the Quarto website.
4. Configuring GitHub Pages deployment.
5. Verifying the generated `github-pages` artifact.
6. Successfully deploying the website to GitHub Pages.

## Deployment

The website is automatically deployed through GitHub Actions and GitHub Pages.

The deployment workflow builds the Quarto website and publishes the generated `_site` content through the GitHub Pages deployment process.
