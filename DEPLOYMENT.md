# Quarto Website Deployment

## Overview

This repository contains the Artificial Intelligence course website built with Quarto.

## Development and Integration

The existing Pull Request issues and merge conflicts were resolved, and the finalized Quarto website was merged into the `main` branch.

## GitHub Pages Deployment

GitHub Actions was configured to build and deploy the Quarto website to GitHub Pages.

The deployment workflow:

1. Builds the Quarto website.
2. Generates the `_site` output.
3. Uploads the website as a `github-pages` artifact.
4. Deploys the artifact through GitHub Pages.

The GitHub Pages deployment was successfully completed.

## Result

The Quarto course website is integrated into the repository and deployed through GitHub Pages.
